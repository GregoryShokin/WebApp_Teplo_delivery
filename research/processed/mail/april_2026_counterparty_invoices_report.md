# Апрель 2026: счета и оплаты по почтовым контрагентам

Дата сборки: 2026-05-22.

Источник:
локальная синхронизация Mail.ru + PDF-вложения из `research/private/mail/attachments/` + сверка с `research/private/tbank/statement_classified.csv`.

Методика:
расход относится к месяцу оказания услуги из PDF-счета/УПД/периода в документе. Дата письма используется только для поиска документа, дата платежа - для сверки оплаты и ДДС. Счет и УПД на один период и одну сумму считаются одним расходом; повторные письма с тем же счетом дедуплицируются по номеру, периоду и сумме.

### Синапс / Яндекс Директ

Сумма счета за апрель: **38 000,00 руб.**

Основание:
по почте есть регулярные отчеты `hello@biz-panel.com`; счет скачан из Biz Panel. Счет № 503711 от 16.03.2026 относится к апрелю 2026.

Путь к источнику:
письмо `hello@biz-panel.com` -> свежая ссылка входа в Biz Panel -> договор `CNTX-212566 от 25 Мар. 2021г.` -> вкладки `Яндекс` и `Счета`. Отчет Яндекс строится как `https://biz-panel.com/node/59505/yandex?begin=YYYY-MM-DD&finish=YYYY-MM-DD`; счета скачиваются как `https://biz-panel.com/node/59505/download-invoice/{invoice_number}`.

Состав счета:

| Строка | Сумма |
| --- | ---: |
| Абонентское обслуживание | 18 000,00 |
| Размещение рекламных материалов Яндекс.Директ | 20 000,00 |

Оплата:
2026-03-26, 38 000,00 руб., ООО «О. О».

В апреле прошел платеж 38 000,00 руб. по счету № 507100 от 16.04.2026; по циклу счетов это, вероятно, следующий период.

Фактический расход кампаний Яндекс Директ за 01.04.2026-30.04.2026 по Biz Panel: **23 984,77 руб.** Детализация: [april_2026_yandex_direct_spend.md](april_2026_yandex_direct_spend.md).

Решение владельца 2026-05-22 для P&L: строка `Контекстная реклама` собирается по варианту A — абонентское обслуживание Синапса из счета за месяц услуги плюс фактический `Бюджет` кампаний из Biz Panel. Абонентское обслуживание не является константой: для каждого месяца его нужно читать из счета Синапса/ООО «О. О» по договору `CNTX-212566`. Для апреля 2026 P&L-сумма строки: **18 000,00 из счета N 503711 + 23 984,77 = 41 984,77 руб.** Строка размещения рекламных материалов из счета используется как сверка платежа/пополнения, но не заменяет фактический `Бюджет`.

## Контрольные замечания

1. По Лемме, iiko и StarterApp суммы подтверждены PDF-документами и относятся к периоду услуги внутри документа.
2. По Синапсу / Яндекс Директ и Синопсису / SEO суммы подтверждены банковскими платежами; прямые счета не сохранены как вложения в письмах.
3. Для автоматизации нужен следующий шаг: отдельный парсер `mail document inbox`, который будет привязывать email-отправителя к контрагенту, вытаскивать PDF/ссылку, распознавать сумму, месяц услуги и сверять с T-Bank платежом.
