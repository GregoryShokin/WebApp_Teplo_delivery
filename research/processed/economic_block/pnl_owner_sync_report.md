## Структура ОПиУ из листа `Статьи`

Блоки:

- `Выручка`
- `Переменные`
- `Прямые постоянные`
- `Общепроизводственные`
- `Административные`
- `Коммерческие`
- `Доходы ниже EBITDA`
- `Расходы ниже EBITDA`

Правила:

- В месячных листах расходные/уменьшающие строки заполняются по влиянию на прибыль: плюс, если строка уменьшает прибыль; минус, если увеличивает прибыль или компенсирует расход.
- Минусовые статьи прямо названы: `Комиссия партнерам (с -)`, `Возвраты клиентам (с минусом)`.
- Прямые статьи распределяются по направлениям `Роллы`, `Пицца`, `Горячий цех`, `Бар`.
- Общепроизводственные, административные, коммерческие и ниже EBITDA не распределяются по направлениям; они идут в `Общее`.
- Формула месяца: выручка минус переменные = маржинальный доход; далее минус прямые постоянные = валовая прибыль по направлениям; минус общепроизводственные = валовая прибыль; минус административные и коммерческие = операционная прибыль EBITDA; ниже EBITDA идут прочие доходы/расходы, проценты, налоги, овердрафт, амортизация, штрафы и пени.

## Вопросы, снятые после чтения `ОПиУ -> Статьи`

- Куда относить курьеров: снято. `Траты на курьерскую службу`, `Общепроизводственные`.
- Куда относить комиссию партнерам: снято. `Комиссия партнерам (с -)`, блок `Выручка`, то есть уменьшает выручку.
- Куда относить эквайринг: снято. `Комиссия за эквайринг`, `Общепроизводственные`.
- Куда относить списания блюд: снято. `Списание продукции и сырья`, `Общепроизводственные`.
- Куда относить ревизии/недостачи/излишки: снято. `Результаты ревизии`, `Общепроизводственные`.
- Куда относить поиск сотрудников: снято. `Поиск и найм персонала`, `Административные`.
- Куда относить маркетинг: снято. `Коммерческие`.
- Что ниже EBITDA: снято. `Прочие доходы`, `Прочие расходы`, проценты, налоги, комиссия за овердрафт, амортизация, штрафы и пени описаны в `Статьи`.
- Какие статьи постоянных расходов должны быть в P&L: снято. Список есть в `Статьи`.
- Источник ФОТ в ОПиУ: снято. ФОТ подтягивается через `Из Отчетов!A1 = IMPORTRANGE(...)` из `2026 Зарплатная ведомость • [ИП Шокина]`, лист `Свод`.
- Исключение из ФОТ-импорта: `Налоги с ЗП` нельзя автоматически брать из зарплатной ведомости, потому что employer-side социальные выплаты вроде ПФР в ведомости не учитываются; основной источник - ДДС статья `Налоги с З/п`.
- `Списание невостребованных депозитов`: источник подтвержден как `Зарплатная ведомость -> Свод`, строка 17; можно подтягивать автоматически, но текущий ОПиУ не менять без отдельной команды.
- `Аренда торговой точки Черникова`: снято. Фиксированная сумма 100 000 руб. в месяц.
- `Коммунальные платежи Черникова`: снято. Ручной ввод по платежкам от арендодателя: вода + газ + электричество.
- `Телекоммуникации`: снято. MVP-формула после решения владельца 2026-05-25 = ручной ввод Mango Office + iHC.ru сервер 600 руб./мес + Микроэл интернет 3 230 руб./мес; ЛК Mango остается backlog для post-MVP автоматизации.
- `Комиссия агрегатору`: снято. Ручной ввод по сумме комиссии за месяц, которую присылают менеджеры агрегатора `К порогу`.

## Максимальный риск искажения прибыли

1. Постоянные расходы после февраля 2026. В `2026 ОПиУ` заполнены только январь-февраль, а черновой P&L идет до мая MTD.
2. Спорные iiko OTHER_EXPENSES без статей в ОПиУ: `Актуализация`, `Всякое Черникова`, `Перемещения`; `Всякое Гагарина` отдельно помечено как исторический контур, не активная операционная статья.
3. `Затраты на персонал` 204 528 руб.: вероятно выше EBITDA, но нужно не задвоить с ФОТ и правильно выбрать статью.
4. Выручка: отдельная строка `Торговая выручка` 41 993 руб. и расхождение между дневным iiko-слоем и iiko P&L.
5. Комиссия партнерам в марте 2026: 0 руб. может завышать прибыль, если это пропуск.
6. ФОТ: источник в ОПиУ подтвержден как `Зарплатная ведомость` через `Из Отчетов`/`IMPORTRANGE`; ручной пересчет ОПиУ не нужен без отдельной команды.
