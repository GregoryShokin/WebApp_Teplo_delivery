## Примененные решения интервью 2026-05-25

1. Mango Office: для MVP выбран ручной ввод владельца. В `pnl_2026_monthly.csv` закрыты компоненты Mango: `2026-02` 11 946,61 ₽, `2026-03` 12 122,02 ₽, `2026-04` 10 189,52 ₽. Вместе с iHC.ru 600 ₽/мес и Микроэл 3 230 ₽/мес итоговая строка `Телекоммуникации`: 15 776,61 ₽, 15 952,02 ₽, 14 019,52 ₽. `2026-05` не закрыт: фиксированные 3 830 ₽ оставлены, Mango = `source_not_loaded`, не 0.
2. Коммунальные Черникова: источник обновлен на платежки арендодателя через Telegram/OCR structured storage. В текущем processed P&L суммы не загружены, строка оставлена `source_not_loaded`; ДДС/банк являются cash-fact, не заменой accrual.
3. Налоги ниже EBITDA: строка `Налоги` начисляется как 7% от iiko OLAP выручки без учета скидок (`УСН 6% + страховые взносы 1%`) только как accrual/model для P&L/API, не как cash-факт. Значения оставлены без пересчета: `2026-02` 315 545,44 ₽, `2026-03` 328 259,05 ₽, `2026-04` 278 286,54 ₽, `2026-05` 189 862,75 ₽ по MTD-выручке. Последняя поправка владельца: cash-выплата `659 783` = только УСН 6%, не сумма 7%; tax payable/1% ведется отдельно по WorkMail `askad02@mail.ru`.
4. Tax payable source: WorkMail `askad02@mail.ru`, письмо `#837` от 2026-05-20 `0,2 %.xls, ЕНП до 28.05.docx`. Разобрано как отдельная задолженность/control, не P&L-дубль: `ЕНП до 28.05.docx` 18 556,93 ₽ и `0,2 %.xls` 78,95 ₽ по травматизму 0,2%; срок из письма - до 2026-05-28, owner close deadline - до 2026-06-30. Период и payment match = `pending_parse`.
5. Налоги с ЗП: строка оставлена отдельно в общепроизводственном блоке, основной источник - ДДС статья `Налоги с з/п`, payroll sheet только контроль. Для `2026-04` чистая сумма payroll taxes после удаления УСН 6%, 1% ИП и tax payable отсутствует в processed-слое, поэтому значение пустое со статусом `source_not_loaded/pending_parse`, не 0.
6. Таргетированная реклама: для MVP оставлена одна строка. Канонический источник уже подтвержден и не требует нового owner-вопроса: WorkMail `smmbux@yandex.ru`, письмо от `ИП Билинский А.Р.` / `ИП Билинский Андрей Романович` с темой `Документы для ИП Шокина Кристина Юрьевна...`; во вложениях УПД по обслуживанию/продвижению и рекламному бюджету. ДДС/T-Bank только cash-сверка. Так как УПД не разобраны в processed-слое, строка = `source_not_loaded`.
7. ФОТ: текущие значения из `payroll_monthly.csv` оставлены как legacy/control, но строки ФОТ помечены `requires_recalc`. Для MVP нужен additive role-only export из Google Sheets `Расчет зарплат NEW`, лист `Свод`, диапазон `C7:C13` и соседние месячные колонки; role-cut и type-cut нельзя суммировать вместе.

Осталось незакрытым в актуальном P&L processed layer:

- `2026-05` Mango: `source_not_loaded`, месяц не завершен; налоги ниже EBITDA уже рассчитаны по 7% от MTD iiko OLAP выручки без скидок.
- `Коммунальные платежи Черникова`: нужен processed export из Telegram/OCR storage.
- `Налоги с ЗП` за `2026-04`: нужна чистая сумма payroll taxes без УСН 6%, 1% ИП и отдельного tax payable; статус `source_not_loaded/pending_parse`.
- Tax payable по WorkMail `askad02@mail.ru`: сумма seed разобрана из письма `#837`, но период и payment match остаются `pending_parse`.
- `Таргетированная реклама`: нужен WorkMail parse по уже подтвержденным УПД ИП Билинский А.Р. из `smmbux@yandex.ru`; источник не переуточнять.
- `ФОТ`: нужен role-only export из `Расчет зарплат NEW Свод!C7:C13`.
- Амортизация, проценты по кредитам, прочие below-EBITDA строки остаются не финализированы по прежним источникам.
