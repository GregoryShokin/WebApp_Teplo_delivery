# Начисления и выплаты

## Реестры

`Выгрузка` — реестр расчетных строк. Структура фактических данных:

| Колонка | Смысл |
|---|---|
| `A` | дата начисления/события |
| `B` | сумма |
| `C` | сотрудник |
| `D` | должность |
| `E` | подразделение/точка |
| `F` | тип строки |
| `G` | комментарий |
| `H` | год, формула `YEAR(A:A)` |

`Выплаты` — реестр денежных выплат. Структура фактических данных:

| Колонка | Смысл |
|---|---|
| `A` | дата выплаты |
| `B` | сумма |
| `C` | сотрудник |
| `D` | должность |
| `E` | подразделение/точка |
| `F` | тип выплаты |
| `G` | комментарий |

`Выплаты` формируются через `IMPORTRANGE` из нескольких внешних таблиц выплат. В исследованной книге это денежный реестр, а не расчет начислений.

## Чем отличаются начисления от выплат

Начисление в `Выгрузка` отвечает на вопрос: "что сотруднику начислено, удержано или перенесено в отдельный фонд".

Выплата в `Выплаты` отвечает на вопрос: "какие деньги реально выданы сотруднику".

В персональном отчете они сводятся в баланс:

```text
баланс = начисления, увеличивающие долг работодателя
       - удержания, штрафы, НДФЛ, депозитные удержания
       - денежные выплаты
       +/- ручные и технические корректировки
```

## Типы начислений в `Выгрузка`

Фактически найдены типы:

- `Оклад`
- `Процент`
- `Премия`
- `Больничные и отпуска и пособия`
- `Накопительный фонд`
- `Списание накоплений`
- `Депозит возврат`
- `Депозит удержание`
- `Депозит списание`
- `НДФЛ Начислено`
- `Штрафы и удержания`
- `Штрафы и удержания` — тот же текст с неразрывным пробелом, потенциальная ошибка качества
- `Штрафы по ревизиям`

## Типы выплат в `Выплаты`

Фактически найдены типы:

- `Выплата ЗП`
- `Выплата аванса`
- `Выплата накоплений`

`Выплата ЗП` и `Выплата аванса` участвуют в персональном отчете. `Выплата накоплений` в формулах персонального отчета явно не участвует, хотя по смыслу должна быть связана с блоком накопительного фонда.

## Денежные и неденежные движения

| Категория | Где живет | Денежное движение сейчас | Влияние |
|---|---|---:|---|
| начислено за период | `Выгрузка` | нет | увеличивает расчетный баланс, кроме специальных удержаний |
| выплачено деньгами | `Выплаты` | да | уменьшает долг работодателя перед сотрудником |
| накоплено | `Выгрузка`, тип `Накопительный фонд` | нет | увеличивает отдельный накопительный фонд |
| удержано | `Выгрузка`, штрафы/НДФЛ/депозит удержание | нет | уменьшает сумму к выплате |
| депозит | `Выгрузка` + `Штат` | обычно нет, пока не возвращен | ведется как удержанный/возвращаемый/списываемый баланс |
| НДФЛ | `Выгрузка`, тип `НДФЛ Начислено` | не выплата сотруднику | уменьшает баланс сотрудника |
| штрафы | `Выгрузка`, типы штрафов | нет | уменьшают баланс сотрудника |
| больничные/отпуска/пособия | `Выгрузка` | нет | увеличивают баланс как отдельный тип начисления |

## Еженедельная ведомость

Лист `Понедельные начисления` агрегирует `Выгрузка` по неделям для `Производство Черникова`.

Ключевые формулы:

- `A2:A` генерирует недели от `DATE(2026,3,3)` до `TODAY()+370`;
- `B2:B` показывает диапазон недели;
- `C:H` суммируют `Оклад`, `Процент`, `Премия`, `НДФЛ Начислено`, `Штрафы и удержания`, `Штрафы по ревизиям`;
- `I:I = Оклад + Процент + Премия - НДФЛ - Штрафы - Ревизии`.

Ограничение: подразделение `Производство Черникова` и стартовая дата 2026-03-03 зашиты в формулах. Если веб-приложение должно поддерживать разные подразделения и произвольные периоды, эти значения надо вынести в параметры.

## Административная зарплата

`Зарплата Администрации` содержит ручной блок:

- должность;
- сотрудник;
- оклад;
- сумма начисления;
- дата начисления;
- тип начисления;
- проверка заполненности;
- сумма выплаты;
- дата выплаты;
- тип выплаты.

В листе есть формула проверки: если есть строка сотрудника, но не заполнена сумма или дата начисления, выводится подсказка `Введите сумму` / `Введите дату`.

Прямой формульной связи `Зарплата Администрации -> Выгрузка` в выгруженном workbook не видно. Вероятно, административные строки переносятся в реестры вручную, импортом или внешним процессом. Это нужно подтвердить.
