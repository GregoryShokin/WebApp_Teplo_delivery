# Инструкции для агентов

## Обязательное правило работы с Git

- Каталог `/Users/grigorii/Developer/Projects/Teplo-all-for-business` — постоянный worktree ветки `main`.
- Никогда не переключай этот каталог на другую ветку и не веди в нём разработку задачи.
- До первого изменения кода создай для задачи отдельную ветку и отдельный sibling-worktree. Используй `scripts/agent-worktree.sh add <имя> <задача>` либо `git worktree add`, если ветка уже существует.
- Перед изменениями обязательно проверь `git worktree list` и `git branch --show-current`: задача должна выполняться не в корневом `main`-worktree.
- Не переноси все незакоммиченные изменения из `main` целиком. Если требуется исправить старую ошибку, отделяй только собственные файлы с явными pathspec и сохраняй чужие изменения.
- Полные правила жизненного цикла веток, портов, деплоя и уборки находятся в `CLAUDE.md`, раздел «Работа с ветками и worktree».
