## Маршрут поиска

1. Прочитай применимые инструкции проекта. Для поиска в кодовой базе используй `graphify` по его скиллу.
2. Если есть `graphify-out/graph.json`, используй существующий граф. Не перестраивай его ради поиска документов.
3. Расширь запрос словами из текущего словаря графа. На 08.10.2026 реально встречались:
   `конкуренты конкурентов конкурент отзывы отзыв reviews competitive суши шеф ниппон роллов`.
4. Выполни `graphify query "<выбранные слова>" --budget 3500`; при недоступном CLI используй read-only traversal из инструкции `graphify`.
5. Проверь найденные файлы через `rg`, затем расширяй поиск только при пробелах:

```sh
rg -n -i 'конкур|отзыв|суши.?шеф|ниппон|ёби|yandex_eda|k_porogu' business-docs/marketing .agents
rg --files business-docs docs outputs .agents research | rg -i 'compet|review|конкур|отзыв|sushi|nippon|feedback'
rg --files --hidden --no-ignore research | rg -i 'compet|review|отзыв|sushi|feedback'
git ls-files '*competitor*' '*yandex_eda*' '*k_porogu*' '*feedbacks_themes*'
git log --all --format='%h %ad %s' --date=short -- 'research/processed/competitors/*'
```

Не считай ссылку на файл доказательством его наличия. Проверь путь физически и отделяй отсутствующий артефакт от нулевого результата анализа. Не сканируй личные данные и секреты ради поиска отзывов.

## Ошибки и ограничения, которые нельзя наследовать

- **Ниппон, сеты:** в `positioning.md` ранние 0,73 ₽/г исправлены ниже на 1,10–1,24 ₽/г по фото ВК. Раннее число названо ошибкой агрегатора. Для текущего расчёта обе июньские оценки требуют обновления.
- **Обещанная скорость:** «45 минут» в рекламе не равны измеренному времени доставки. Условия на разных страницах могут расходиться — сохраняй обе версии и конфликт.
- **Чужой город:** не подставляй Волгоградские цены вместо Волгодонских при географическом ограничении сайта.
- **Каналы и ассортимент:** «не нашли сайт/приложение/пиццу/акции» в июне не означает их текущего отсутствия. Поле `not_found_in_checked_sources` отличается от подтверждённого `absent`.
- **Достоверность отзывов:** разрыв рейтингов платформ не доказывает накрутку; отсутствие известного фильтра отзывов не гарантирует достоверность каждого текста. Старые категоричные обвинения не превращай в факты.
- **Оценка владельца от 08.10.2026:** Карты использовать с пометками. По его сведениям, отзывы Суши Шефа и Ёби Даёби на Картах могут быть недостоверными, у Ниппона этой проблемы нет. Яндекс Еду для Суши Шефа использовать. Храни как `owner_assessment` с датой и источником; не объявляй всю платформу гарантированно честной.
- **Сеть и филиал:** отзывы приложения сети из нескольких городов могут описывать авторизацию и интерфейс, а не вкус еды в Волгодонске. Не смешивай эти сущности.
- **Популярность блюда:** число в URL Суши Шефа может быть ID товара; используй подписанный счётчик оценок, а не ID.
- **Состав и себестоимость:** полный состав и массы ингредиентов в прежней конкурентке не сохранены. Общий вес и фото не дают точной рецептуры; последующий расчёт веди по явно указанным ингредиентам и обозначенным диапазонам масс на ценах Тепла.
- **Стратегия:** старые ограничения «не снижать цены» или «не копировать сет» не являются действующим запретом. Новые инструкции владельца допускают эти изменения при обоснованном росте прибыли.
