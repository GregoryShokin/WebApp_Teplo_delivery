## Источники и чтение

- API-ответы прочитаны в авторизованной native Chrome сессии через GET/SaveAs. Оставшиеся карточки прочитаны обычным UI; источник starter-ui-details-projection.json сохранён в observed_ui_detail без превращения в API. Настройки, начисления и сообщения не изменялись.
- [Полный реестр JSON](starter-inventory-2026-10-07.json): raw, полные ID, settings, SHA256, `saved_at_utc`. Это время файла, не подтверждённый `fetched_at_utc`; списки и detail не являются атомарным снимком.
- Дни 1…7 ↔ Пн…Вс подтверждены сравнением UI/API для 1515, 1216 и «Удвоение». Часовой пояс движка и точные временные границы не установлены. Абсолютные даты при отборе кандидатов трактованы включительно; на граничной дате нужна проверка движка.
- Явный API null означает, что этот параметр в сохранённой карточке не задан. Это отличается от непрочитанной карточки. Нулевой общий минимум не является неизвестным минимумом.
- `repeatable=false` сохранён как raw: не переводить его в «один раз в жизни». Числовой персональный лимит отражён отдельно в `availableCountForUser`; общий — в `usagesCap`.
- Имена наград из UI хранятся отдельным свидетельством об акции. Не склеивать Starter mealId с Server GUID/analyticId и не подбирать товары по похожим именам.

**Шкала подарков.** При большем пороге sortIndex меньше. UI говорит, что больший номер применяется позже, а lastApplicable прекращает последующее применение скидок (в UI отдельно оговорены бонусные баллы). Не складывать четыре подарка по наличию четырёх active. `goal=true` отвечает за отображение цели; это не отдельное разрешение совместимости.
**Самовывоз.** `deliveryType={choice:toChosen,entityIds:[pickup]}` точно ограничивает его самовывозом. Применение 10% идёт к totalPrice; оно само не останавливает дальнейшие скидки (lastApplicable=false).
**Совпадение приоритета.** У самовывоза, подарка от 2999 и первого заказа sortIndex=1. Порядок при равенстве, проверка порога до/после скидок и итоговая совместимость не установлены. Поэтому нельзя обещать «10% + старший подарок» только из этих полей.
**Первый заказ / реферал.** `f8f244ac-69b2-44c9-bbea-5f9cd6036979` помечен isReferral=true, первый заказ, один раз на клиента по числовому лимиту; 15% от 1500 ₽. Это не тот GUID, который реферальная страница показывает как linked discount (`7295d0cb-baa0-475c-8bc3-ce026cd61e3f`), и не промокод «первый» с 20%. Одноимённые сущности не объединять. Факт реферальной привязки к legacy GUID разбирается отдельно в справке лояльности.
