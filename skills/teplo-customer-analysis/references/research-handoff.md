# От клиентского анализа к персональному исследованию

## Первая очередь

Владелец выбрал бывших постоянных клиентов, которые перестали покупать.
Отбирай их по истории до снижения и нынешней активности, затем разбей по
продуктам, выгодам, опыту и вкладу. Добавь сравнение с продолжающими покупать
постоянными и отдельную группу одного заказа без повтора. Не смешивай их причины
в единственный процент «по всей базе».

Ранжирование по прошлому вкладу полезно для приоритета возврата, но исследование
потребностей не должно состоять только из самых денежных или жаловавшихся клиентов.
Отбирай также случаи без жалоб и с разной историей выгод. Неответивших показывай
отдельно; дозвон/готовность говорить создают смещение выборки.

## Карточка для сценария

Передавай в [teplo-customer-research](../../teplo-customer-research/SKILL.md):

| Поле | Содержание |
|---|---|
| participant_id | Аналитический ключ; контакт отдельно для разрешённого обращения |
| as_of / coverage | Дата, глубина истории, известные/непокрытые каналы |
| segment_now / segment_before | Правила обоих сегментов, даты, исходные R/F/M |
| purchase_pattern | Последний заказ, прежний интервал и его надёжность, изменение частоты |
| product_pattern | Повторные блюда/сеты, оплаченные позиции отдельно от подарков |
| benefits_used | Фактические скидки/бонусы/подарки, текущий баланс отдельным снимком |
| contribution | Горизонт, полный/частичный расчёт, не «чистая прибыль клиента» |
| experience | Оценки/жалобы/компенсации с датами и источниками, известный результат решения |
| uncertainties | Возможная смена канала, недостаток истории, ненадёжные временные отметки |
| questions | Конкретные пробелы, которые может закрыть разговор |

Не считай нынешний customer.ordersCount количеством заказов на дату старого отзыва.
Для исторического сегмента нужны заказы, совершённые к тому моменту. Если отзыв нельзя
надёжно связать с заказом, передавай его как отдельный опыт с этой оговоркой.

## Формат, выбранный владельцем

Для этой задачи подходит короткий **структурированный диагностический опрос**:
нейтральные варианты вероятных причин, выбор главной, затем конкретное уточнение.
Свободный ответ доступен; развёрнутое открытое интервью не является обязательным
предварительным этапом. Формат не должен заставлять человека согласиться с негативом.

Пример ветвления для кандидата на отток:

1. Проверить предпосылку: продолжает заказывать Тепло с другого профиля/канала;
   реже заказывает доставку вообще; выбирает другие места; иная ситуация/не помнит.
2. Если выбирает другие места — нейтрально выяснить решающее отличие: итоговая
   цена, конкретные блюда/вкус/начинка/размер, сроки/температура/стабильность,
   решение проблем, удобство, другое. Допустить «проблем в Тепле не было».
3. Если упомянул негатив — уточнить конкретный последний случай, повторяемость,
   ожидание и факт, обращение и результат. Не начинать с «вас подвела доставка»
   только из-за iiko-отметки или предыдущей жалобы.
4. Если покупал по акциям — уточнить, знал ли условия и изменились ли они для него;
   использование акции не доказывает, что без неё он не купил бы.
5. Выбрать наиболее важное изменение. Обсуждать конкретную новую цену/выгоду
   только после расчёта исполнимого предложения. Намерение вернуться не считать заказом.

Для одного заказа — ожидания и причина отсутствия второго; для снижения частоты —
изменение потребности и доли Тепла среди покупок; для продолжающих покупать —
что удерживает и какие неудобства принимают. Ответы сохраняй с отметкой
`spontaneous`/`prompted`, показанными вариантами, порядком и версией сценария.

Из Revvy используй клиентские реплики и контекст, не исходящие шаблоны как отзыв.
Порог «негатив» там включает 4 при настройке позитив=5; сохраняй исходную оценку.
Общее количество чатов не равно числу ответивших или отзывов.

## Сводка для решения

Покажи отдельно по сегментам: размер подходящей базы, отбор, приглашённых,
дозвонившихся/ответивших, завершивших; число людей с каждой причиной и знаменатель.
Один человек может назвать несколько причин; главную причину храни отдельно.
Сопоставь ответы с заказами, противоречащие случаи тоже показывай.
Разделяй: факт покупки, системную отметку, объяснение клиента, гипотезу аналитика,
результат проверки изменения. Для продуктовой гипотезы укажи целевую группу,
ожидаемый механизм и расчёт экономики перед разработкой позиции.
