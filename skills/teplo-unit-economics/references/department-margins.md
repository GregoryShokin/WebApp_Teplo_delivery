# Маржинальность по цехам: обязательная граница модели

**Уточнение владельца 15.10.2026:** модернизация, увеличение начинки, повышение
качества ингредиентов и изменение рецептур сейчас относятся **только к роллам**.
Пицца, шаурма и остальные блюда горячего цеха сохраняют рецептуры и сырьевые рубли
на единицу. Это ограничение применять во всех следующих расчётах до нового решения.
Обжаренный/запечённый ролл остаётся роллом; общую работу фритюра/саламандры нельзя
целиком отнести к новым рецептурам, если там готовят и другие блюда.

## Порядок и формулы

1. Собери SKU → продуктовая линия/цех → состав/количество → чистая выручка →
   фактическая сырьевая стоимость. Не распространяй целевой FC роллов на весь оборот.
   iiko `CookingPlace` — исходная учётная группировка, не всегда точная продуктовая
   граница. Проверяй SKU и раскрывай смешанные сеты; неизвестную долю показывай явно.
2. Сохрани прежние рубли сырья на единицу всех незатронутых продуктов. При неизменных
   объёмах их сумма неизменна. При росте их продаж растут количество и затраты, но не
   дороговизна рецепта. Различай сценарий роста только роллов и роста всех заказов.
3. Для каждого цеха `FC_j = C_food_j / R_net_j`; по бизнесу
   `FC_total = sum(C_food_j) / sum(R_net_j)`. Проценты нельзя усреднять арифметически.
   Сырьевая маржа = `1−FC`, вклад после переменных затрат и чистая прибыль — другие показатели.
4. Бюджет улучшения при фиксированной цене/объёме:
   `delta_C_food = R_net_rolls × target_FC_rolls − C_food_rolls_base`.
   Остальные цеха остаются в базе, а не получают ту же новую ставку.
   После отдельного пересмотра скидок НЕ повышай сырьевые рубли автоматически:
   возврат выручки сам уменьшает FC%. Для нового рецепта сначала фиксируй рублёвый бюджет.
5. Скидки/бонусы заказа распределяй между подходящими SKU по проверенному факту POS
   или явно выбранному пропорциональному правилу. Исключённые товары не получают
   начисления/списания; порог по всей корзине и сумма подходящих товаров различаются.
   Подарки и компоненты сета учитывать один раз, с раскрытием рецептуры.
6. Смешанный сет пицца+роллы: повысить стоимость только ингредиентов роллов; пиццу
   оставить прежней. Не относить весь сет к роллам только по родительской строке.
   Для FC линии нужна разумная явно описанная аллокация net-выручки сета; для общей
   прибыли достаточно единой выручки родителя и корректной суммы затрат компонентов.
7. Общие расходы сохраняются **один раз на весь бизнес**. Доставка — на заказ/зону/
   смену; упаковка — по составу; эквайринг/налоги/Starter — по своим базам; дневной
   процент ФОТ — общий. Не списывать всю аренду/администрацию/курьеров на каждый цех.
   Дополнительный труд/энергия/потери — только затронутые операции; общие бюджеты
   распределять явно, не принимать бухгалтерскую аллокацию за предельные затраты.
8. Большая корзина обычно снижает доставку в процентах от чека, но не гарантирует
   меньшие минуты упаковки или меньше продуктов в абсолюте. Один адрес может
   требовать дополнительных пакетов/времени/машин. Считать экономию на заказ против
   дополнительных продуктовых затрат и денежной скидки, не назначать её процентом.
9. Мощность считать по минутам/машинам затронутых цехов и смешанным заказам, а не
   по одной общей выручке. Улучшение роллов не подтверждает запас других участков.

## Контрольный пример из рабочей базы августа 2026

Источник: `business-docs/finance/unit-economics/kitchen-modernization/snapshots/2026-10-14/b-costs-baseline/data/orders-and-thresholds.json`,
`2026-08.units_by_cooking_place`. Весь бизнес: выручка3 282 430,64 ₽,
сырьё962 639,64 ₽. Группа «Суши»: выручка1 744 246,11 ₽,
сырьё523 844,90 ₽, FC≈30,03%. Это временный proxy цеха, пока не проверены все SKU;
специи учтены отдельной группой и не удорожаются автоматически.

Если условно поднять FC **только «Суши» до32%**, дополнительный бюджет сырья
≈34 314 ₽/мес, общий FC≈30,37%. Ошибочное применение32% ко всему бизнесу
давало≈87 738 ₽, завышая прибавку примерно на53 424 ₽/мес **до прочих драйверов**.
Пример при прежних ценах/продажах; не включает ещё пересмотр акций, изменение спроса,
новые смены/технику. Не называть эту разницу чистой экономией или готовой ценой меню.

Предыдущая модель `snapshots/2026-10-15/offer-scenarios/` и сравнение quality32 в
`discount-pressure/` сохраняются как история допущений. Их32% для всего бизнеса
**не соответствует текущему ограничению владельца**; последующие версии рассчитывать
по цехам и не цитировать прежние пороги как актуальные без пересчёта.

## Уточнение после раскрытия смешанных наборов в этом же срезе

В owner-offer-v2 проверены SKU и компоненты трёх акционных наборов. Выручка набора
распределена по долям фактической себестоимости компонентов — явная аналитическая
аллокация, а не цена продажи каждого компонента. Роллы: R≈1 748 559,20₽,
C≈522 458,91₽, FC≈29,88%; прочие продукты440 180,74₽ не удорожаются. Бюджет
перехода только роллов к32% теперь≈37 080,04₽, общий FC≈30,46%. Это уточнение
имеет приоритет над proxy группы «Суши» выше для следующих расчётов.

Новые решения по акциям, бонусам и границам —
[в отдельной справке](owner-offer-policy-2026-10-15.md). Прежний сценарий32% всего
бизнеса сохранён как история, не как действующая граница задачи.
