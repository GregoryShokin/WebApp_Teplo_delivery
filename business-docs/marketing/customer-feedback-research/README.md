Не искать первоисточники только в `/tmp`: временные копии могут исчезнуть. На другой машине локального архива может не быть — проверить manifest, затем восстановить через [метод Starter](methods/starter-feedback.md) или исходный источник, не считать отсутствие локального файла отсутствием отзывов.

## Как получить свежую выгрузку Starter

[Проверенный способ, поля, фильтры и ограничения](methods/starter-feedback.md).

```bash
python3 business-docs/marketing/customer-feedback-research/scripts/collect_starter_feedback.py \
  --out "$HOME/Documents/Teplo/Customer Feedback Research/NEW-SNAPSHOT/starter"
```

Подставить новый датированный каталог вместо `NEW-SNAPSHOT`. Скрипт не перезаписывает прежние первоисточники. Секреты читает из разрешённого локального `.env`, cookie хранит в памяти; вызывает только вход и читающие методы отзывов. `--env` позволяет указать другой разрешённый файл. По умолчанию tenant зафиксирован как `https://crm.starterapp.ru/fmteplo`.

## Что агенту делать дальше

1. Прочитать этот README и manifest нужного источника. Выбрать период, ресторан и цель до анализа.
2. Для тем Starter читать оригинальные комментарии: словарь содержит 11 тегов, но во всех 10 535 записях массив tags пуст. Отсутствие тега не означает отсутствие проблемы. Все 1 310 текстов за 2025–2026 смыслово размечены в ranking-2025-2026; оставшиеся тексты 2023–2024 не входят в текущую задачу. Полная разметка всех 3 814 текстов не заявляется.
3. Отделять оценки без текста, текст клиента, ответ компании, медиа и тематическую разметку. `accepted/processed` — статус обработки, не тональность.
4. Сохранять связь кода с feedback ID, метод и дату. У одинаковых текстов могут быть разные события; уточнения одного эпизода не считать новыми жалобами.
5. Не прибавлять массивы автоматически: Карты уже входят в Revvy, а Starter и Revvy могут описывать тот же заказ. Для внутреннего объединения нужны source order IDs и подтверждённое соответствие, одной даты/фразы недостаточно.
6. Отзывы дают гипотезы о пережитом опыте. Новые опросы должны помогать выбирать изменения для роста заказов; оценка/намерение не доказывают прирост. Цена среди некупивших этим корпусом не измеряется.
7. Новый результат сохранять рядом в новом срезе, обновлять `sources.json` и этот указатель. Временная выгрузка и один пересказ без данных/метода не считаются завершённым сохранением.

## Почему прежнее исследование было трудно найти

В старом индексе маркетинга указано, что документы июня восстановлены 29.07.2026 из сессий после переезда проекта. Указанный там `research/processed/starter/feedbacks_themes.md` отсутствует в текущем и прежнем checkout, а также в проверенной истории Git. Это объясняет наличие старых выводов без массива. Свежие материалы октября находились в отдельном worktree; здесь собрана их постоянная копия и добавлены указатели из корневого `AGENTS.md` и индекса маркетинга.
