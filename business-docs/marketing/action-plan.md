# Тепло — План действий (Фаза 4)

*Начато: 2026-06-16. Переход от дорожной карты (Фаза 3, `roadmap.md`) к исполнению. Рычаги сгруппированы в ВОЛНЫ по зависимостям, а не по скору: предусловия и бесплатное — первыми; корневые длинные (скорость/лосось) — стартуют сразу параллельно, потому что они долгие.*

*Решения владельца 2026-06-16: маркетинг-шаги исполняются ВНУТРИ/самостоятельно (Starter/Senler) — поэтому «маркетинг» в таблицах = владелец/внутренний ресурс. **СТАРТ — Волна 0 целиком.***

## Принципы исполнения
- **Holdout на каждый измеримый рычаг** (контроль 10–20% сегмента) — иначе вслепую (корень 2.4). Без holdout-инфры (H0-2) измеримые рычаги не стартуют.
- **Замер like-for-like, решение по данным**, не по интуиции (особенно шкала 1699, потолок, ценовые).
- **Корневое — рано.** Скорость и лосось не дают быстрого скора, но это главные течи → запускать параллельно с волны 0, не ждать.
- **Сроки в неделях — ориентир**, многое упирается в вендора Starter и поставщиков.
