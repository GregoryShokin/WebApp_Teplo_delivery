# Карта замеров суши-цеха

> **Черновик, не утверждённый регламент.** 14.10.2026, редакция после перехода на видео. Одна страница для
> сотрудников кухни. Полный протокол — `method.md` рядом (§2А — видео).

**Зачем.** Решаем, помогут ли кухне машины для риса и роллов. Меряем работу, а не человека: итоги считаем по цеху,
без оценок и штрафов. Работайте в обычном темпе. Забыли записать — пропустите строку, не придумывайте цифры.

**Время роллов записывать не нужно — его считает видео.** Ниже только то, чего камера не видит.

**На станции:** этот бланк и ручка; настенные часы; весы с кнопкой «тара».

## Камеры — правила для всех

- Камеры не загораживать, на объектив ничего не ставить и не вешать.
- **Поднос** между формовкой и отдачей всегда на своём месте.
- **Старший смены:** в начале и в конце записи показать каждой камере телефон с секундами — 5 секунд.

## 1. Рис — каждую партию (пишет тот, кто варит)

| № | Сухой рис, г | Включил варку (часы) | Варка готова | Заправку начал | Заправку закончил | Ёмкость пустая, г | Ёмкость с рисом, г | Готовый рис, г |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | |
| 2 | | | | | | | | |

**Как взвесить:** сухой рис — до промывки. Готовый рис — после заправки: сначала взвесить пустую ёмкость, потом с рисом; разницу записать в последнюю графу.
**Конец смены:** остаток риса ____ г → выбросили / оставили / другое: ______.

## 2. Переделка — отмечать каждый раз (камера видит, что переделали, но не видит почему)

**Переделка** — когда вы ещё раз что-то делаете с уже сделанным роллом или делаете его заново до передачи: перекрутили, перерезали, заменили кусочек, выбросили. Решаете как обычно, по правилу кухни.

| Время | Кто (Ф1 / Ф2 / О) | Код | Что выбросили |
|---|---|---|---|
| | | | |

Коды: **Р** — развалился или порвался · **Н** — плохо нарезан · **Т** — топпинг или шапка · **С** — не тот ролл или состав · **Д** — другое (написать словами).
Что выбросили: **весь** / **N кус.** / **ничего**. Пример: «18:42, О, Н, 2 кус.».

## 3. Электричество — только старший смены

В начале и в конце смены перепишите показания счётчика-розетки у каждой машины (кВт·ч). Счётчик не выключайте и не переставляйте. Электрощит не трогать — с ним работает только электрик.

**Конец смены:** отдайте бланк управляющему, он в тот же день перенесёт его в таблицу.

---
*Для управляющего.* До съёмки — письменно предупредить сотрудников о камерах и цели замера. В тестовый день
один человек с секундомером засекает 10–20 роллов (крутка у каждого формовщика, нарезка у отдачника) — по этим
цифрам проверяем точность видео (`method.md` §2А.4). Роллы для разбора: Цезарь, Хоккайдо, Камчатский,
Запечённая Калифорния, Жареная Калифорния, Лава краб, Классический с крабом, Филадельфия лайт; запас — Честер,
Тори Яки, Сакура.
