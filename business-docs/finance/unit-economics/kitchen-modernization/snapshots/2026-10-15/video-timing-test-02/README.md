# Проверка точности хронометража по таймеру — тест № 2, 15.10.2026

**Результат:** временная шкала видео согласуется с секундомером. На проверенной нарезке слепая оценка занижена примерно на **0,5 с** (около 5% от десятисекундного этапа). На длинном участке «готовый мат → порция в контейнере» оценки совпали при округлении до десятых. Это проверка одного ролика, не доказанная точность всех будущих замеров.

Владелец уточнил: важна правильность измерения времени, одинаковый ролл с первым видео не нужен. Поэтому новое видео исследовали самостоятельно: другой агент закрыл движущийся экран телефона, основной агент разметил только кадры с маской, сохранил неизменяемую версию и SHA-256, после чего открыл независимые показания таймера. **Длительности двух разных роллов не сравниваются как ошибка.** Ограничение про тот же дубль в тесте № 1 относится к прямой проверке его конкретных событий; новый слепой тест на другом ролле полностью допустим.

Числа до тысячных оставлены для воспроизводимости, а не как обещание такой точности. Прикладной вывод: для хорошо видимых действий в этом ролике слепая разметка с шагом около 0,5 с дала расхождение порядка полусекунды на короткой операции. Рабочий запас 0,5–1 с разумен как предварительное допущение для подобных условий, но ещё не подтверждён на выборке. Для действий длительностью около секунды требуется более частая разметка и отдельная проверка.

## Отдельно проверены часы и смысловые границы

**Шкала времени.** Таймер запущен после начала записи. Ранний якорь: на 5,000 с видео он показывает 1,29 с; сдвиг нуля составляет 3,71 с. Этот единственный якорь использован без подгонки скорости. На шести дальнейших точках 20–147,5 с максимальное числовое расхождение с экраном — 0,027322 с. Практически это согласование лучше 0,1 с с учётом обновления экрана/экспозиции. Оно не означает, что действие распознано с точностью до сотых, и не исключает любой возможный монтаж между выбранными кадрами.

**Нарезка.** Вслепую первое режущее движение отнесено к 125,017–126,017 с видео, последнее — к 135,015–135,515 с. При независимом просмотре с шагом 0,1 с: начало 125,116666–125,316666 с, конец 135,315–135,515 с. Середина выбранного начала была позднее примерно на 0,30 с, конца — раньше примерно на 0,15 с; это объясняет недооценку длительности примерно на 0,45 с по видео и 0,48 с по отображаемому таймеру. Исходная слепая разметка не исправлена задним числом.

**Укладка.** Руки отпускают порцию в открытом контейнере между 146,013–146,513 с видео. Контейнер не закрыт. Начало получения риса частично за кадром, поэтому первое появление риса и запуск секундомера не объявлены точным началом всей работы повара.
