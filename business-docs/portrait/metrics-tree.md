# Дерево метрик

## Главная управленческая цель

Бизнес должен быть управляемым по прибыли, денежному потоку, качеству сервиса и росту повторных заказов.

Главный результат:

```text
Операционная прибыль = Выручка - переменные расходы - постоянные расходы
```

## 1. Выручка

```text
Выручка = Количество заказов x Средний чек
```

| Метрика | Зачем нужна | Частота |
| --- | --- | --- |
| Выручка за день | Видеть выполнение плана | Ежедневно |
| Количество заказов | Понимать спрос | Ежедневно |
| Средний чек | Управлять меню, допродажами и акциями | Ежедневно |
| Выручка по часам | Видеть пики и провалы | Еженедельно |
| Выручка по дням недели | Планировать смены и маркетинг | Еженедельно |
| Выручка по каналам | Понимать, откуда приходят деньги | Еженедельно |

## 2. Маржинальность заказа

```text
Маржа заказа = Чистая выручка - себестоимость - упаковка - доставка - комиссии - скидки
```

| Метрика | Зачем нужна | Частота |
| --- | --- | --- |
| Себестоимость, % | Контроль food cost | Ежедневно / еженедельно |
| Валовая прибыль | Понимать реальную прибыльность продаж | Ежедневно |
| Скидки, % | Видеть, не покупаем ли выручку слишком дорого | Ежедневно |
| Стоимость доставки на заказ | Контроль логистики | Еженедельно |
| Комиссии агрегаторов | Оценка реальной выгоды канала | Еженедельно |
| Списания | Контроль склада и производства | Еженедельно |

## 3. Маркетинг

```text
Маркетинговая эффективность = Новые заказы + повторные заказы - стоимость привлечения
```

| Метрика | Зачем нужна | Частота |
| --- | --- | --- |
| Расход на рекламу | Контроль бюджета | Ежедневно |
| Заказы с рекламы | Оценка результата | Ежедневно |
| CAC | Стоимость привлечения клиента | Еженедельно |
| Доля новых клиентов | Понимание роста базы | Еженедельно |
| Доля повторных клиентов | Понимание удержания | Еженедельно |
| Повторный заказ за 30 дней | Оценка качества продукта и сервиса | Ежемесячно |
| ROMI | Рентабельность маркетинга | Ежемесячно |
