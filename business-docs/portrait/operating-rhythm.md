# Ритм управления

## Цель

Сделать контроль бизнеса регулярным: каждый день видеть факт, каждую неделю понимать причины, каждый месяц принимать стратегические решения.

## Ежедневно

| Действие | Кто | Результат |
| --- | --- | --- |
| Проверить выручку, заказы, средний чек |  | Понимаем выполнение дневного плана |
| Проверить скидки, отмены, возвраты |  | Видим потери |
| Проверить опоздания и жалобы |  | Видим проблемы сервиса |
| Проверить стоп-лист и списания |  | Видим проблемы кухни и закупок |
| Зафиксировать 1-3 задачи на день |  | Команда понимает фокус |

## Еженедельно

| Действие | Кто | Результат |
| --- | --- | --- |
| Разобрать план-факт по выручке |  | Понимаем динамику продаж |
| Разобрать каналы заказов |  | Понимаем эффективность маркетинга |
| Разобрать себестоимость и списания |  | Контролируем маржу |
| Разобрать ФОТ и смены |  | Контролируем производительность |
| Обновить список узких мест |  | Выбираем главные действия недели |

## Ежемесячно

| Действие | Кто | Результат |
| --- | --- | --- |
| Собрать управленческий P&L |  | Видим реальную прибыль |
| Собрать денежный поток |  | Видим кассовые риски |
| Оценить маркетинг по ROMI и CAC |  | Понимаем, что масштабировать |
| Провести меню-анализ |  | Понимаем, что продвигать, менять или убирать |
| Поставить цели на следующий месяц |  | Есть план по продажам, прибыли и задачам |

## Формат короткой ежедневной планерки

1. Что было вчера по план-факту?
2. Где отклонение и почему?
3. Какие 1-3 действия делаем сегодня?
4. Кто отвечает?
5. Как вечером поймем, что задача выполнена?

## Формат еженедельного разбора

1. Что произошло с выручкой, заказами и средним чеком?
2. Какие каналы выросли или просели?
3. Что произошло с маржей?
4. Где были операционные потери?
5. Какие гипотезы проверяем на следующей неделе?
6. Какие задачи снимаем, добавляем или меняем?
