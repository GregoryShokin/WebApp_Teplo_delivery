# Инвентаризация данных

## Цель

Понять, какие данные уже есть, какие можно выгрузить из iiko, какие лежат во внешних системах, а какие пока не собираются.

## 1. Выгрузки из iiko

| Блок | Что нужно выгрузить | Период | Зачем |
| --- | --- | --- | --- |
| Продажи по дням | Выручка, заказы, средний чек, скидки, возвраты | Последние 6-12 месяцев | Сезонность, динамика, план-факт |
| Продажи по часам | Заказы и выручка по часам | Последние 3 месяца | Пики нагрузки, расписание смен |
| Продажи по категориям | Пицца, роллы, сеты, напитки, допы | Последние 6 месяцев | Структура выручки |
| Продажи по блюдам | Количество, выручка, себестоимость, маржа | Последние 6 месяцев | Меню-инжиниринг |
| Заказы по каналам | Сайт, телефон, агрегаторы, приложение, мессенджеры | Последние 6 месяцев | Эффективность каналов |
| Скидки и акции | Тип скидки, сумма, канал, заказ | Последние 6 месяцев | Цена промоакций |
| Отмены и возвраты | Причина, сумма, смена, канал | Последние 6 месяцев | Потери и ошибки |
| Клиенты | Новые, повторные, частота, средний чек | Последние 12 месяцев | Удержание и LTV |
| Доставка | Время приготовления, время доставки, опоздания | Последние 3-6 месяцев | Контроль сервиса |
| Склад | Закупки, остатки, списания, инвентаризации | Последние 3-6 месяцев | Контроль food cost |
| Персонал | Смены, часы, роли, начисления | Последние 3-6 месяцев | ФОТ и производительность |

## 2. Внешние источники

| Источник | Данные | Зачем |
| --- | --- | --- |
| Бэк-офис API | Sales reports, продажи, зарплаты, выплаты курьеров, операционные отчеты | Автоматический сбор факта без ручных выгрузок |
| Google Drive | ДДС, ОПиУ / P&L, баланс, внутренняя управленческая документация | Сверка управленческого учета и восстановление картины финансов |
| Рекламные кабинеты | Расход, показы, клики, заявки, заказы | CAC, ROMI, масштабирование |
| Сайт / аналитика | Трафик, конверсия, источники | Поиск провалов в воронке |
| Телефония | Входящие, пропущенные, конверсия в заказ | Потерянные заказы |
| Банк / касса | Поступления, расходы, остатки | Денежный поток |
| Таблицы управленческого учета | Постоянные расходы, займы, выплаты | Реальная прибыль |
| Отзывы | Оценки, жалобы, причины негатива | Качество и удержание |
| Карты / геосервисы | Рейтинг, видимость, отзывы | Локальный спрос |

## 4. Минимальный первый пакет данных

Чтобы начать диагностику, достаточно собрать:

1. Продажи по дням за последние 6 месяцев.
2. Продажи по блюдам и категориям за последние 3-6 месяцев.
3. Заказы по каналам за последние 3-6 месяцев.
4. Скидки и акции за последние 3-6 месяцев.
5. Себестоимость или food cost по категориям.
6. Расходы на рекламу по каналам за последние 3 месяца.
7. Постоянные расходы за последние 3 месяца.
8. ФОТ за последние 3 месяца.
9. Отмены, возвраты, жалобы за последние 3 месяца.
10. Данные по новым и повторным клиентам, если доступны.

## 5. Приоритет автоматизации

| Приоритет | Источник | Что автоматизируем первым | Почему |
| --- | --- | --- | --- |
| 1 | Бэк-офис API | Продажи по дням, заказам, каналам, блюдам | Это основа выручки и маржи |
| 2 | Бэк-офис API | Зарплаты и выплаты курьерам | Быстро показывает нагрузку ФОТ и доставки |
| 3 | Google Drive | ДДС и ОПиУ / P&L | Нужна сверка управленческой прибыли с фактом денег |
| 4 | Google Drive | Баланс | Нужно восстановить, так как давно не ведется |
| 5 | Реклама и телефония | Расходы, лиды, пропущенные, конверсия | Позволяет считать CAC, ROMI и потерянные заказы |
