# Поставщики с обязательным НДС по товарам в накладных

## Проблема

Часть поставщиков работает с НДС, и по их товарам НДС нужно фиксировать при
внесении накладной. Сейчас такого требования нет — НДС по товарам не выделяется,
что мешает корректному учёту.

## Предложение

- Пометить в справочнике **поставщиков** признак, что поставщик работает с НДС
  (для него указание НДС по товарам обязательно).
- При **внесении накладной** от такого поставщика — требовать **указание НДС по
  товарам** (построчно/по позициям товара).
- Для поставщиков без признака поведение не меняется.

## Ценность и приоритет

Корректный учёт входящего НДС по накладным официальных поставщиков; основа для
последующей отчётности. Приоритет уточняется владельцем.

## Зависимости и риски

- Модуль «Склад → Накладные» и справочник контрагентов/поставщиков — точка
  внедрения; надо согласовать с двусторонней синхронизацией iiko и запретом товара
  без номенклатуры.
- Платежи по таким накладным отражаются в будущей странице **«Платежи»**
  ([[FEAT-003]]).
- **Открытые вопросы к владельцу:**
  - Ставка(и) НДС: одна на поставщика, выбор из списка ставок, или ввод по позиции.
  - Как НДС хранится и отображается: сумма, ставка, «в т.ч. НДС» vs «сверху».
  - Ретроспектива: применять ли к уже внесённым накладным или только к новым.
