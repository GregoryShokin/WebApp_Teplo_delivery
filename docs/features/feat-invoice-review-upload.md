## Поведение

Ручная загрузка обычного счёта больше не заканчивается пустой формой коммунального разбора.
Для него используется общий распознаватель счетов. Коммунальные документы сохраняют свой
обработчик: получатель задаётся потоком, а не реквизитами ресурсника в квитанции.

В форме показаны получатель, реквизиты, сумма, номер, дата, НДС, строки документа и предложения
по длительности. «6 месяцев» хранится отдельно от начала услуги. Пользователь выбирает месяц
старта; октябрь 2026 и 6 месяцев дают 01.10.2026–31.03.2027. Явные даты можно исправить.

До создания проверяется ИНН. Существующая карточка используется повторно. Новая карточка
может быть полностью настроена из формы: реквизиты, статья ДДС и способ учёта. «Подписка /
услуга за период» использует существующий `fixed_tariff`, без изменения правил ОПиУ.

Есть две кнопки: сохранить готовый счёт или подтвердить и создать банковский черновик.
Сохранение счёта и карточки — одна транзакция. Отказ банка не удаляет сохранённый счёт.
Повторный разбор сохраняет ручные поля и проверенные реквизиты. Повторная отправка после
таймаута использует один `document_id` для одного набора счетов и банковского провайдера.
Изменение банковского payload после неопределённого результата блокируется до проверки
прежнего черновика. Конкурирующие отправки сериализуются блокировкой строк счетов.

PDF показывается локально через PDF.js, без зависимости от встроенного браузерного плагина.
Просмотрщик и worker загружаются только при открытии PDF. Из документа не выполняется JS.

## Внешнее распознавание

Автоматическая проверка отклонила включение нового пути передачи документов, поскольку
нужны отдельные согласованные payload и destination. Подключение подготовлено и проверено
с подставными ответами; новая передача по умолчанию выключена:

```
INVOICE_REVIEW_EXTERNAL_LLM_ENABLED=false
INVOICE_REVIEW_LLM_BASE_URL=https://api.anthropic.com
```

После явного согласования можно включить первый флаг и настроить ключ Anthropic. В запрос
идёт PDF или фотография целиком в base64, инструкция извлечения и схема структурированного
ответа. Содержимое включает текст, реквизиты, суммы, даты и строки документа. История банка,
пароли и существующий реестр контрагентов в запрос не добавляются. Модель по умолчанию —
существующий `INVOICE_RECOGNITION_MODEL`, `claude-sonnet-4-6`.

Для ручного разбора: таймаут модели 45 секунд, без автоматических повторов. При отказе
сохраняются извлечённые локально поля и возможность ручного ввода. Решения о создании
контрагента и отправке принимает пользователь.
