# Индекс документации

## Цель

Создать управляемую картину бизнеса доставки пиццы и роллов: понимать финансовые и маркетинговые показатели, видеть ежедневные задачи, быстро находить узкие места и принимать решения на основе фактов.

## Принцип работы

Каждый важный вывод фиксируем в формате:

| Блок | Что фиксируем |
| --- | --- |
| Факт | Что реально происходит в бизнесе |
| Источник | Откуда взяли данные: iiko, реклама, телефония, банк, CRM, вручную |
| Дата | За какой период данные |
| Вывод | Что это значит для бизнеса |
| Действие | Что делаем дальше |

## Текущая фаза

Сейчас мы не строим стратегию вслепую. Сначала собираем базовую картину:

1. Как бизнес зарабатывает деньги.
2. Где теряет деньги.
3. Какие каналы дают заказы.
4. Какие блюда, районы, смены и сотрудники влияют на результат.
5. Какие данные уже есть в iiko, а какие нужно начать собирать.
6. Какие решения нужно принимать ежедневно, еженедельно и ежемесячно.

При этом каждый собранный источник, processed-файл и правило расчёта рассматриваем как будущую спецификацию для единого веб-приложения: см. [17-unified-management-app.md](17-unified-management-app.md).

## Важное правило источника

Для P&L/ОПиУ главный источник по выручке, скидкам и себестоимости по направлениям - iiko OLAP `Отчет о выручке по направлениям`. Следующие агенты должны начинать поиск этих данных с него. Google Sheets `ОПиУ` хранит ручной перенос и управленческую раскладку, а processed CSV являются снимками для анализа.
