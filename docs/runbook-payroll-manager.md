# Runbook менеджера: недельная ЗП

## 1. Сделать ЗП за неделю
1. Откройте `/schedule/shifts-ledger` (`График сотрудников` -> `Учёт смен`), выберите `Дата окончания недели` и нажмите `Обновить неделю из iiko`.
2. В `Учёт смен` разберите строки `требуют выбора`: назначьте роль/категорию, поправьте ошибочные смены.
3. Откройте `/payroll` -> вкладка `Расчёты`. Для новой недели нажмите `Запустить расчёт за неделю ...`; для уже созданного прогона нажмите `Пересчитать`.
4. Откройте прогон: проверьте по сотрудникам `Часов`, `Оклад`, `Премия`, `%`, `Штрафы`, `Удержание депозита`, `К выплате`, `Нал / РС`.
5. Если блокеров нет, нажмите `Финализировать`.

## 2. Если расчёт заблокирован
1. В карточке прогона смотрите верхний блок `Невозможно финализировать: ... блокер(ов) в расчёте`; в списке прогонов статус будет `Блокеры`.
2. У проблемы нажмите `Перейти в Штат` или `Открыть смену`:
   - `Неизвестный сотрудник в iiko-явках` / `Сотрудник требует настройки`: `Штат` -> `Загрузить из iiko` или `Создать сотрудника`; заполните должность, payroll-роль, категорию.
   - `Не указана роль для расчёта` / `Не указана категория сотрудника`: исправьте карточку сотрудника или роль в `Учёт смен`.
   - `Явка требует проверки`: откройте смену и проверьте время/сотрудника.
3. `Смена через полночь` в блоке `Требует проверки (не блокирует финализацию)` - предупреждение, не блокер.
4. После правок нажмите `Пересчитать`, проверьте суммы и `Финализировать`.

## 3. Добавить премию или штраф
1. Откройте `/payroll/adjustments` (`Премии и штрафы`) и нажмите `Добавить`.
2. В `Новая премия / штраф` заполните `Тип`, `Сотрудник`, `Дата`, `Категория` или `Другое`, `Сумма, ₽` и `Комментарий` с причиной.
3. Нажмите `Сохранить` -> `Создать`, затем в нужном прогоне нажмите `Пересчитать`.

## 4. Безопасно сменить должность
1. В `Штат` меняйте должность/роль с правильной даты начала.
2. Если задевается закрытая неделя, появится 409 и диалог `Затронута закрытая неделя`; отметьте `Понимаю, потребуется корректировка ведомости` только если готовы править ведомость.
3. Ошибка в закрытой ведомости: прогон -> `Вернуть в работу` -> причина -> правка -> `Пересчитать` -> `Финализировать`.

## 5. Отметить выплату
1. После финализации при необходимости в `Нал / РС` нажмите `Указать нал/РС`, задайте наличную часть и `Сохранить`.
2. Для безнала нажмите `Сформировать черновики в банке` - черновики создаются по суммам `РС`.
3. В `Выплата` нажмите `Выплачено` по сотруднику или `Отметить все выплаченными`; укажите `Дата выплаты` и `Способ`.

## 6. Если ошиблись после финализации
1. Откройте прогон -> `Вернуть в работу`, укажите причину.
2. Исправьте источник: `Учёт смен`, `Штат`, `Премии и штрафы` или `Нал / РС`.
3. Нажмите `Пересчитать`, проверьте суммы, снова `Финализировать`.
4. Если выплата уже прошла, смотрите блок `Дельты выплат`: `Доплата` оформляется отдельным черновиком, `Излишек` остаётся зафиксирован на бизнес-карте.

## Частые проблемы -> решение
- `Неизвестный сотрудник в iiko-явках` -> `Штат` -> `Загрузить из iiko` или `Создать сотрудника`, затем `Пересчитать`.
- `Сотрудник требует настройки` -> заполнить должность, payroll-роль, категорию, при необходимости ПИН/дату приёма.
- `Смена через полночь` -> проверить глазами; это предупреждение `Требует проверки (не блокирует финализацию)`.
- Премия/штраф не попали в расчёт -> проверьте дату корректировки и нажмите `Пересчитать`.
- После финализации кнопки правки недоступны -> `Вернуть в работу`, исправить, `Пересчитать`, снова `Финализировать`.
