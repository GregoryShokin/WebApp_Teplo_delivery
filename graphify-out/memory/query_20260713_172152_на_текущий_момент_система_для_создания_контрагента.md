# Q: На текущий момент система для создания контрагента требует только имя. Нужно, чтобы обязательно была указана статья контрагента. Если у контрагента нет статьи, у тебя такого быть не может. Давай на всякий случай мало ли нужно будет сделать контрагента без статьи, будет тоггл для этого. Конкретно чтобы явно менеджер указывал, что у контрагента нет статьи, а не просто забыл. То же самое реквизиты для официальных поставщиков: обязательно указать реквизит. Официальное название это: БИК БАНКА, ИНН, РАСЧЁТНЫЙ СЧЁТ, КОР СЧЁТ. КПП не обязательна.

## Answer

Expanded from original query via graph vocab: [counterparty, create, article, dds, requisites, official, supplier, validate, route, dialog, profile, payment]. Канонический и legacy DDS пути создания используют общий create_counterparty. В общий сервис добавлена обязательная статья ДДС либо явный флаг confirm_no_dds_article. Для relationship=official и role=supplier обязательны bankBik, inn, bankAcnt и recipientCorrAccountNumber; КПП необязательна. Форма блокирует создание до выполнения тех же условий.
