Production evidence: draft f2281308-f5df-435d-965a-4c3e6dd0dc16 has provider_ref 019f5d35-cb7e-7deb-9fe9-e483b151dcf5 and local status created. poll_payment_statuses runs every minute and queries provider_ref. Direct T-Bank /api/v1/payment/status returns SUBMITTED with comment Платеж исполняется, not EXECUTED. Direct current statement fetch contains no outgoing 6000 RUB operation, so local paid transition must not run yet. Public POST /api/v1/webhooks/tbank/payment-status is reachable and returns 401 without configured bearer token; token is configured. No matching webhook log exists for this payment, which is expected until T-Bank emits a terminal document status/account operation. Official T-Bank docs say payment-status webhook is only for payments executed through API; manually signed drafts rely on document-status polling plus account-operation webhook. Registration of the account-operation webhook is external and cannot be proven from repository config alone.
