# Q: Интеграция приложения со СБИС ЭДО: методы по контрагентам, счетам, УПД, актам и использование электронной подписи

## Answer

Expanded from original query via graph vocab: integration auth credential secret token document counterparty invoice organization sync webhook tbank. Архитектура проекта уже имеет DataSource, SourceCredential, SourceSnapshot, ParsedDocument, Counterparty, SupplierInvoice и APScheduler. Рекомендуемый первый этап — read-only Saby service app, курсорная синхронизация СБИС.СписокИзменений, backfill через списочные методы, локальный архив XML/PDF/SGN и материализация только платежных документов. Электронная подпись для чтения API не нужна; она нужна для подписания, отправки, утверждения и части служебных этапов. Закрытый ключ не хранить в БД; текущий value_encrypted не имеет envelope encryption. Для КЭП выбрать ручное или отложенное подписание, автоматизацию подписи вынести в отдельный поздний этап.
