# Q: Логика видимости уволенных сотрудников в накопительном фонде: без начислений убрать сразу, со списанием оставить forfeited до выплаты фонда

## Answer

Expanded from original query via graph vocab: [fund, employee, dismissal, dismissed, forfeited, payout, ledger, accumulation, contribution, status]. list_fund_accounts() показывал каждый годовой счёт, поэтому нулевые счета уволенных выглядели active. Добавлен fund_account_visible_in_roster(): активные сотрудники остаются, уволенные без денежных движений скрываются, forfeited с начислениями остаются до settlement. payout_fund_accounts_for_year() после фактической выплаты года помечает forfeited-счета settled_at, после чего они исчезают из операционного списка без удаления истории. forfeit_active_fund_on_dismiss() сохраняет статус forfeited и сбрасывает settlement для нового списания.
