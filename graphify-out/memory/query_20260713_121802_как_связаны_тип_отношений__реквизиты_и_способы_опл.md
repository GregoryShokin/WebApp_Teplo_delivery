# Q: Как связаны тип отношений, реквизиты и способы оплаты при создании контрагента?

## Answer

Банковские реквизиты и ИНН сохраняются при создании только для official. Для informal реквизиты очищаются, а оплата продолжает идти через карту ИП/Сейф; для barter реквизиты очищаются, расчёт остаётся взаимозачётом по сальдо. В форме удалена категория ledger, ИНН перенесён во вкладку Реквизиты, сама вкладка заблокирована для неофициального и бартерного типов.
