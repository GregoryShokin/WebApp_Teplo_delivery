# Q: Как работает окно активных платежей и создание нового платежа; почему официальный контрагент ушёл на карту ИП и удалённый черновик остался активным?

## Answer

Окно Новый платёж всегда направляло expense-строки через карту ИП и Сейф, используя counterparty_id только как атрибуцию. Исправлено: официальный или бартерный контрагент с подтверждёнными реквизитами создаёт одно-строчный прямой банковский черновик по своим реквизитам; paid-переход создаёт прямую расходную проводку по выбранной статье, а aggregator показывает черновик в активных платежах. Для статусов включён минутный scheduler polling с выбором клиента по bank_provider; T-Bank PAYMENT_NOT_FOUND в resultError трактуется как удалённый черновик. ActivePaymentsModal перечитывает DB каждые 10 секунд.
